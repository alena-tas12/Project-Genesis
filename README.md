**Project Genesis** is an enterprise-grade computational platform for simulating, analyzing, and benchmarking educational architectures across global sovereign nations and institutional workforce capacity building.

It combines a **12-module deterministic simulator core**, **17 global educational system models**, a **7-stage lifelong learning pipeline**, interactive **3D WebGL spatial visualizers**, and a specialized **SIH 2026 Problem Statement 26101 (MoSPI DIID) Capacity Building & AI Assessment Engine**.

## 🌟 Key Features

### 1. SIH 2026 Problem Statement 26101 (MoSPI DIID) Integration
- **Cadre Competency Shortage Heatmaps**: Analyzes capacity across **ISS**, **SSS**, **FOD**, **SDRD**, **DPD**, and **DIID** cadres.
- **Competency Gap Radar**: Measures gaps between current officer skills and target roles in *National Accounts*, *AI/ML Imputation*, *GIS Remote Sensing*, and *Cloud Data Pipelines*.
- **AI Document NLP MCQ Generator**: Converts uploaded training manuals (PDF/DOCX/TXT) into structured Multiple Choice Questions classified by **Bloom's Taxonomy** (*Remembering* $\rightarrow$ *Evaluating*) and **Distractor Fallacy Logic**.
- **Closed-Loop Competency Feedback**: Automatically recalculates and updates official readiness scores and skill-gap percentages in real-time as assessments are completed.
- **iGOT Karmayogi API Telemetry**: Simulated OAuth 2.0 and OpenAPI v2 payload telemetry sync for national server integration.

### 2. 17 Global Educational Presets & 195+ Country Taxonomy
- Features preset configurations for **Traditional**, **Montessori**, **Finnish**, **Japanese**, **AI-Assisted**, **Waldorf**, **Reggio Emilia**, **IB Diploma**, **Harkness**, **Sudbury**, **Singapore Math**, **Prussian Industrial**, **South Korea Suneung**, **Germany Dual VET**, **France Baccalauréat**, **China Gaokao**, and **India NEP 2020**.
- Complete taxonomy mapping all 195+ sovereign nations into 12 educational archetypes.

### 3. 7-Stage Lifelong Education Pipeline
- Models student trajectory from **Early Childhood (0–5)** through **Primary (6–14)**, **Secondary (15–18)**, **Undergraduate (18–22)**, **Postgraduate (22–26)**, **Doctoral (26–32)**, and **Adult Upskilling (32–75)** with high-stakes gatekeeper exams.

### 4. 3D WebGL Spatial Classroom & Campus Visualizer
- Built using **Three.js** to render real-time 3D spatial classrooms, student desks, AI tutor holograms, 3D geographical campus maps with transit commute lines, and 3D floating Knowledge DAG spheres.

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript 5.7, Vite 6.2
- **3D Graphics & Visuals**: Three.js WebGL, Lucide Icons, Canvas API
- **Mathematics & Engine**: Mulberry32 PRNG (Bit-for-Bit Seed Reproducibility), Ebbinghaus Memory Retention Decay Model
- **Styling**: Modern CSS Glassmorphic Variables, Responsive Grid Layouts
- **Persistence**: LocalStorage state persistence & reproducible JSON/CSV export packages

## ⚡ Quick Start & Installation

```bash
# Clone the repository
git clone https://github.com/alena10-05/educational-system-simulations.git

# Navigate into project directory
cd educational-system-simulations

# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```

The application will be available locally at `http://localhost:5173/`.
